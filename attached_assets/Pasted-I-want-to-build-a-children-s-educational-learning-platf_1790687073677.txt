Product Concept

For the first MVP, we are focusing only on:

Grade 1 → Mathematics → Addition

The application has two main experiences:

Child

The child can:

Learn lessons through short vertical educational videos.
Complete interactive homework.
Practice and prepare for exams.
Receive friendly guidance when making mistakes.
Earn progress/rewards from actually learning.
Parent

The parent can:

See what the child studied.
See homework completion.
See practice/exam performance.
Understand the child's strengths.
See which concepts need more practice.
