The Homework and Exam experiences are not implemented according to the product concept we agreed on.

Please update these two experiences while keeping the existing visual design and overall style.

# 📝 HOMEWORK

Homework should have TWO ways to add homework.

## Option 1 — Select a textbook page

The parent should be able to enter/select:

**Grade → Subject → Book → Page Number**

For example:

**Grade 1 → Math → Page 18**

The application should know which lesson and questions are associated with that page and display the homework questions.

The child then solves the questions one by one.

The system should track:

* Question progress
* Answers
* Attempts
* Correct/incorrect answers
* Concepts that need practice
* Homework completion

The parent should not have to manually type every question.

## Option 2 — Take a photo of the homework page

The parent should also have an option:

**📷 Scan Homework**

The parent takes a photo of the homework page.

The system should then:

**Photo → Read the page → Identify the questions → Convert them into interactive questions**

For example, if the photo contains:

2 + 3 = __
4 + 1 = __
3 + 3 = __

the application should turn these into individual interactive questions for the child.

The child should then solve them one by one.

### Important

Do not implement this as a simple file upload page.

The intended experience is:

**Parent takes photo → application understands the homework → child gets interactive questions**

If OCR/AI functionality is not fully implemented yet, build the complete UI and integration structure so it can be connected properly later.

# 🎯 EXAM / TEST

The Exam experience should NOT be a normal list of questions.

It should feel like a **learning adventure / treasure hunt**.

The child starts at the beginning of a map.

For example:

🏠 START
↓
🌳 Question 1
↓
🌉 Question 2
↓
🏰 Question 3
↓
🌲 Question 4
↓
🗻 Question 5
↓
💎 TREASURE

Each location represents one exam question.

The child can only move to the next location after answering the current question.

When the answer is correct:

* Show positive feedback
* Animate the character moving forward on the map
* Unlock the next location

When the answer is incorrect:

Do not immediately end the exam.

Show supportive feedback and allow the child to try again or receive a hint according to the existing learning logic.

The goal is to make the exam feel like:

**"I'm going on an adventure and solving challenges to reach the treasure."**

rather than:

**"I'm taking a test."**

---

# QUESTION TYPES

The exam should use different question interactions.

For example:

* Multiple choice
* Drag and drop
* Matching
* Visual counting
* Direct answer
* Ordering

Different questions can use different interaction types.

---

# 🏆 FINAL TREASURE

After the child successfully completes the final question:

The character reaches the treasure.

Show a larger celebration:

🎉 Confetti
✨ Stars
💎 Treasure chest
🎊 Celebration animation

Then show the exam result in a child-friendly way.

For example:

**You did it! 🎉**

**You completed your Math Adventure!**

---

# 🎁 REWARD SYSTEM

After completing the exam, show a reward screen.

The reward should be configurable by the parent.

For example, the parent could set:

**"After finishing the exam, you can choose a small reward."**

Possible rewards could include:

* A favorite snack
* Extra play time
* Choosing a cartoon
* A small treat
* Another reward chosen by the parent

The application should present this as a positive celebration, not as an automatic promise of food.

The parent should eventually be able to configure the reward.

For now, build the UI and data structure needed for this reward concept.

---

# IMPORTANT UX PRINCIPLE

Homework and Exam should feel different.

### Homework

**Real school homework → Interactive questions → Adventure → Completion**

It can come from:

* A textbook page
* A photographed homework page

### Exam

**Questions → Adventure Map → Progress through the map → Treasure → Celebration → Parent-configured reward**

Do not make either experience feel like a traditional school form.

Keep the experience:

* Visual
* Interactive
* Child-friendly
* Animated
* Encouraging
* Easy for a Grade 1 child to understand

Keep all existing approved designs and connect these experiences to the existing backend/database.

Do not redesign the Addition learning experience.

Implement these updated Homework and Exam flows as part of the existing application.
