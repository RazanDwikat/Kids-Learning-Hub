بالتعليق الصوتي احكي «هلا» بدل «هسا»، وابدأ بشرح شو هو المشروع قبل الجولة.

**Why:** The user rejected the short promotional animation and screenshot slides, then repeatedly reported voice/action desynchronization and requested this wording and opening explanation.

**How to apply:** Record real moving interactions and scrolling, with synchronized synthetic female Arabic narration in a natural first-person presentation style. Check sentence/action timing, not merely chapter duration. Preserve existing user data by using an isolated demo profile. Do not substitute screenshot slides or claim synthetic narration clones the user's voice.
